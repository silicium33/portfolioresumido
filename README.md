# Portfólio — Gustavo Sirqueira

Página estática de trabalhos selecionados em cerâmica.

## Como abrir

Abra `trabalhos-selecionados.html` em um navegador.

## Como adicionar um projeto

1. Coloque a imagem na pasta `ASSETS`.
2. No HTML, adicione um `<figure>` dentro de `.work-grid`, com um botão `.image-expand`, a imagem e uma legenda `<figcaption>`.
3. Use o caminho relativo `ASSETS/nome-do-arquivo.jpg` no atributo `src`.
4. Mantenha os projetos na ordem cronológica desejada. Os arquivos atuais seguem a numeração dos nomes.

As imagens abrem ampliadas na própria página e podem ser fechadas pelo botão **Fechar** ou pela tecla **Esc**. Prefira JPEG, PNG ou WebP para compatibilidade com navegadores.
